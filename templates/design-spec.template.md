# Design Spec · <项目／页面>

方案阶段填写会影响实现的字段，通常一张表即可。用户确认后，把规格、所选参考和目标代码交给开发 Agent。有影响的未定事项留在方案阶段解决。

| 项 | 本次决定 |
|---|---|
| 状态和范围 | 待确认 / 已确认（用户消息或规格版本）；目标用户、平台、主任务与交付物。涉及实现时给路由、目标页面或组件。 |
| 设计方法与视觉依据 | 主 Skill 和必要专项，记录直接调用、采用官方指引或未访问。给来源及一份主参考、项目界面或本项目草图，写明具体沿用的可见特征。 |
| 内容与布局 | 布局模式、真实内容的优先级、主操作入口和代表区域。按需给标题、主按钮等关键文案，以及实际素材或确认过的替代。 |
| 视觉系统与材质 | 语义色、字体与字阶、间距、圆角和层级的值或项目 token。说明素材比例、裁切和回退，以及阴影、玻璃等效果的用途。 |
| 组件与状态 | 导航、主/次按钮、表单、表格/卡片、浮层中实际用到的组件；外观与现有组件映射、相关状态、焦点与操作反馈 |
| 组件细节（涉及新样式或打磨时） | 用一个实际控件写清圆角及相邻边缘、边框与阴影各自用途；给出悬停和按压分别改什么、时长与缓动、键盘焦点和触屏反馈。优先引用现有 token；细节见 [组件手册](../references/visual-details.md)。 |
| 响应与动效 | 窄屏重排、隐藏或保留的内容；选择的动效触发、属性、时长、缓动；减少动效与材质失败回退 |
| 验收 | 桌面与窄屏等适用视口、代表区域及对照对象。给主路径入口和一个会改变布局或反馈的关键状态。查主次、组件一致性、边缘和反馈；演示数据明确标注。 |

多页项目共享规则按 [主规范维护](../references/design-md-schema.md) 处理，可用 [项目主规范模板](DESIGN.template.md)。本规格引用版本和 token 源，按页面记录差异。中途变更先更新对应字段，确认规则见 [Skill 入口](../SKILL.md)。
