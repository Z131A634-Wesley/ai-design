# 移动任务 · Mobile

适合手机操作、预约、现场检索、列表详情；设备适配优先。H5 可以采用本规范，原生控件和返回随平台。宽屏精确跨列比较或品牌叙事另选对应预设。

~~~css
--canvas: #f1f5f2;
--surface: #ffffff;
--surface-hover: #eaf4ee;
--text: #152d25;
--muted: #4d675e;
--line: #d1ddd5;
--control-line: #64796d;
--accent: #1b634f;
--accent-hover: #134936;
--on-accent: #ffffff;
--focus: #1b634f;
--accent-soft: #ddf0e5;
--error: #a03238;
~~~

- **字阶**：system-ui 或原生动态字体。页标题 30/35、小标题 20/26、正文 16/24、辅助 13/18；保留系统放大，名称太长时让主要数据重排。
- **布局**：4/8/12/16/20/24/32/40 px。窄屏边距 16 px、主路径单列。顶部承担定位和返回；只有存在 3–5 个高频同级目的地才上底部导航，并预留安全区。Web 宽度约 640 px 后可考虑导航 rail；到 860 px 再看是否有两栏任务需要。原生按可用窗口、方向和系统惯例判定。
- **组件**：主要按钮 48–52 px、10 px 圆角；触点建议 44–48 px 起。卡片 12 px 和细边线，平级列表优先分隔线。输入框 48 px、实线边框；错误贴近标签/字段，提交和反馈不被系统键盘遮挡。导航当前项以文字和 accent-soft 展示；浮层用 0 8px 24px #152d2520。
- **动效**：按压和选中 120–160 ms，详情或底部面板 180–240 ms ease-out；保留可见返回、焦点恢复和输入。减少动效取消大位移。拖动等手势同时提供可点击替代。
