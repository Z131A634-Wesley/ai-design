# 技术产品 · Signal

适合 AI、基础设施、开发工具的官网或发布页。先把产品能力变成可读的对比、演示或数据，再决定构图。高频后台和长阅读页优先选对应预设。

~~~css
--canvas: #101319;
--surface: #181e28;
--surface-hover: #202936;
--text: #f0f4fb;
--muted: #a8b5c7;
--line: #344154;
--control-line: #65758b;
--accent: #b5ed76;
--accent-hover: #c9f69f;
--on-accent: #172411;
--focus: #c8fded;
--secondary: #93c8ff;
--accent-soft: #233723;
~~~

- **字阶**：system-ui 或已有技术品牌无衬线；数据/代码用 ui-monospace。首屏标题 56–80 px / 0.98–1.06，窄屏 38–48 px / 1.05；二级 28/34、正文 16/25、数据辅助 13/19。显示数字用 tabular-nums。
- **布局**：4/8/12/16/24/32/48/72 px。桌面内容最大 1200 px，边距 28–40 px；文字和产品证据可以是非对称分栏，或让证据占一整条网格。窄屏 ≤760 px 单列，边距 18–20 px，标题 → CTA → 演示。证据以实际输入/输出为主体，步骤区有独立节奏。只有一个高权重主动作。
- **组件**：主按钮 46 px 高、6 px 圆角、浅绿实底；二级动作可用文本或描边。演示容器 10–12 px，线框用 line，控件/选区边界用 control-line；标签说明指标和状态。选中用边线/标记加 accent-soft；键盘焦点 2 px 实线。图标和色彩围绕演示的用途。
- **动效**：反馈 140–180 ms ease-out；如用滚动叙事，仅一个解释产品的时刻，推荐 240–420 ms、位移 8–16 px；性能不足或减少动态效果时静态。必要的渐变留在演示框周围，文本使用稳定底色。保留作者选择构图或强调色的自由，条件是映射到规格和实际证据。
