# 前端实现

先定位项目实际的框架、主题 token、组件、路由和测试脚本。复用已有的表单、表格、弹层、按钮和状态样式。原生 HTML 优先用语义元素和 CSS 自定义属性；Vue、React 按项目现有组件、样式和状态惯例接入。

- 用已确认规格来决定样式。主题是运行时值的唯一维护处；文档引用角色和位置。手写新组件时，先实现该控件需要的默认、悬停、焦点、禁用、等待、错误等状态。
- 用真实标题、长文案和数据试排。提供自然流式布局，窄屏按任务重排；二维信息可在命名容器里横滚。检查键盘顺序、焦点恢复、滚动容器及过渡效果。
- 检查真实素材授权和裁切；图片预留宽高，首屏关键图优先，后续内容按需加载。分析到瓶颈时再优化动画和资源。
- 保持项目现有工具链，运行与改动相关的 build、typecheck、lint 和测试。用浏览器核对设计与行为。涉及高阶视觉效果时看 [动效与材质](effects.md)；只有现有能力无法实现确认的效果时才评估依赖。

详细步骤见 [交互](interaction-ux.md) 和 [验收](quality-gates.md)。
