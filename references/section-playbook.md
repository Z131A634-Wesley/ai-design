# 营销构图

以真实内容中最能回答访客疑问的证据为起点。按场景选择画面：产品用途用任务或界面证明；空间与实物用真实图像；内容和作品用代表性内容；服务用出发点、结果和具体过程。无法提供真实图时可用原创插图、排版或明确标注的产品演示。

| 模块 | 决定方式 |
|---|---|
| 首屏 | 先辨认产品、目标用户、主价值和下一步。把主动作放进目标视口的自然阅读顺序；次动作以不同视觉权重表达。按真实标题断行，不套统一字数。 |
| 产品证据 | 真实的界面、演示、案例或实物优先。示例数据标注，演示要能操作；静态例图有明确语义。 |
| 导航 | 根据目的地数量和实际任务选顶栏、折叠菜单或锚点。窄屏、键盘和吸顶遮挡按实际行为核对。 |
| 叙事与页尾 | 顺序可以是价值 → 证据 → 如何使用 → 可执行的下一步；为真实内容调整，不凭空加入客户、声明或链接。 |
| 节奏和动效 | 按内容给出段落密度变化、有限的对齐线和背景层次。动画给关键变化反馈，内容先可读可用。 |

用长标题、素材缺失、窄屏和主转化路径压测。首屏只有品牌名或装饰而无法解释用途时，先重做信息层级。[视觉诊断](visual-craft.md) · [营销页面规格](../templates/page-spec.template.md)
