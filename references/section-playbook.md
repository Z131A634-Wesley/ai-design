# 营销页面：板块选型手册

适用于官网、作品集和落地页，不给登录、后台、App 或流程强加 Hero、Footer 或转化 CTA。下文的字数、数量、密度、布局与节奏是营销页选型参考；品牌、可用性与实际内容优先。

**先选型号，再写代码。** 用途：把"翻画廊找灵感"压成"做一次决策"。

按 [取材地图](source-map.md) 对照真实案例：用 Supahero 选首屏构图，用 Navbar Gallery 看信息如何容纳，用 Footer Design 和 CTA.gallery 分别核收束与转化。不要只选一个分类名；写下实际对齐线、视觉主角、屏幕重排和段落衔接。以下矩阵按访客需要看到的证据组织。另可参考 [Taste Skill](https://github.com/Leonxlnx/taste-skill) 的内容选型与宽窄屏复审方法。

## 一、首屏：先选证据，再排构图

| 访客先要弄清什么 | 首屏构图起点 | 检查方式 |
|---|---|---|
| 产品怎么用 | 文案与真实产品画面并列；视觉锚定一个代表任务 | 裁成窄屏后仍能辨认操作或成果；静态画面别伪装成可点击演示 |
| 实物或空间是什么样 | 大幅实物/场景，配与图分离或有足够对比的标题 | 用真实或明确标注的素材；焦点裁切与文字实际对比都要核对 |
| 作品/内容值不值得看 | 一个代表作占主位，旁边给分类、标题或短导语 | 不要把多个同权重视觉堆成无焦点；保留清楚浏览入口 |
| 这个服务能解决什么 | 以价值主张与动作排出主轴，按需要加一条真实证据 | 不靠装饰、假指标或长说明补足定位；窄屏不压住主要入口 |
| 过程如何创造价值 | 首屏先交代结果，后续用顺序场景展示原因 | 动效仅在改善理解时使用；减少动效或不滚动时，关键含义仍看得懂 |

有多个合理方向时，分别用实际标题、素材和主要动作排一遍，以认知成本和资产可行性取舍。不要为填主视觉而虚构成品、门店或案例。

**首屏硬性要求（不论哪型）**
- 价值主张 ≤ 12 个字能读完；**一个**主 CTA，同屏不许第二个同权重按钮
- 不滚动就知道：这是什么、给谁、下一步点哪
- 桌面 1440×900 下主 CTA 不被折线切掉
- 大字不爆行：标题 ≥ 40 字时先做长标题压力测试（换三组长短不同的文案试排）

## 二、导航八型（分类法来自 Navbar Gallery）

| 型号 | 适用 | 判据 |
|---|---|---|
| **静态 / 吸顶** | ≤ 5 个一级项、单页 | 长页用吸顶；滚动后必须变样（高度或背景），否则和内容糊在一起 |
| **下拉 / 飞出** | 有二级但层级浅 | 二级 ≤ 8 项；hover 与 focus 都要能开 |
| **巨型菜单 Mega Menu** | 终点 > 15 个，需分组和说明 | 必须有分组标题；移动端必须换形态，不能硬塞 |
| **侧边栏** | 后台、文档、带筛选的列表 | 可折叠；记住展开状态 |
| **搜索栏** | 内容量大、搜索是主路径 | 必须真能搜，且有空状态 |
| **公告条** | 有促销 / 发布 / 状态要通告 | 可关闭；关掉后布局不跳 |
| **全屏菜单** | 品牌强、项目少、要沉浸 | ≤ 6 项；打开锁滚动；Esc 可关 |
| **面包屑** | 层级 > 3 层 | 是定位工具不是主导航，不要塞满 |

**结构规格**
- 高度：桌面 64–80px；滚动后 68 → 56px 或背景转实
- 移动端：一级项 > 3 个就折进菜单，别横向挤压
- 当前页必须标记（`aria-current="page"` + 视觉差异）
- 吸顶导航配 `scroll-margin-top`，否则锚点被盖

## 三、Footer 十一风格（分类法来自 Footer Design）

`排版型 Typographic` · `大字型 Large Type` · `小字型 Small Type` · `插画型 Illustrative` · `网格型 Grid` · `扁平型 Flat` · `动效型 Animated` · `卡片型 Cards` · `亮底型 Bright` · `暗底型 Dark` · `粗重型 Bold`

**信息上限原则：最多 4 个信息块**
品牌（logo + 一句定位）｜导航（≤ 4 列 × ≤ 6 项）｜法务与联系｜订阅或社交（择一，≤ 4 个图标）

**必须**：可点联系入口（邮箱或表单）；版权年份自动更新；暗底上次要文字对比度仍 ≥ 4.5:1
**禁止**：8 个以上社交图标；每列十几个链接；"Back to top" 带弹跳动画；Footer 再放一遍完整导航

## 四、CTA 分类与强化

**按目标**：购买 · 试用 · 下载 · 订阅 · 预约 · 联系
**按形态**：内联按钮 · 表单 · 弹窗 · 导航条 CTA · 浮层

**五条规则**
1. **一屏一个主 CTA。** 同屏两个同权重按钮 = 用户不选
2. 主次视觉权重要可区分：主实心、次描边或纯文字是可选手段；视觉权重不等于对比度比值
3. 动词开头、≤ 5 词、说清代价（`免费开始` 优于 `了解更多`）
4. 高风险动作（付费/删除/发布）降级为描边，或加二次确认 / hold-to-confirm
5. 触控目标 ≥ 44×44px（WCAG 底线是 24×24，见 `quality-gates.md`）

**强化手法**（磁吸 / tilt / 进度填充 / hold-to-confirm / 微光扫过）
**一页最多 1 种。** 两种以上就是马戏团。

## 五、区块节奏（"高级感"的真正来源）

- 同一页**至少两种区块宽度**：满幅 / 容器内 / 更窄的阅读列。全页等宽 = 平
- **对齐方式要切换**：全居中 → 至少插一段左对齐或贴边
- 相邻区块**背景换一次**（换 surface 或明度），否则连成一片
- 长页在 2/3 处插一个**呼吸区**（大留白 / 大字号单句 / 全幅图）
- 数据、价格、规格用**表格或等宽**呈现，不要用一堆卡片堆
- 卡片半径至少**两级**（内容卡 ≠ 行动卡），否则落入 SaaS 卡片套件特征
