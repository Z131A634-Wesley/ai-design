# 场景选型

先按主任务定结构与交互，再通过 [外部设计 Skill 调用](external-design.md) 定视觉语言。已有参考和项目设计系统决定约束。同一工具的官网、编辑器和帮助页有不同任务，可以共用品牌、字体、基础控件和语义色。

| 场景 | 布局起点与边界 |
|---|---|
| 企业后台 / SaaS 管理系统 | 按 [业务界面](product-ui.md) 从异常、筛选、队列和详情开始。精确跨列比较保留列关系。视觉强调给状态与行动。 |
| 企业官网 / 产品落地页 | 按 [营销构图](section-playbook.md) 用真实产品、实物或案例决定首屏构图。媒体或文字谁做主角由内容决定，保留清楚的主行动。 |
| Web App / 工具 | 按 [工具工作区](workspace-ui.md) 区分输入—结果、连续编辑、列表处理和媒体浏览。画布或内容占主要面积，必要时加工具栏或检查器。 |
| 手机 H5 / 移动 App | 按 [移动平台](mobile-ui.md) 选择单列任务、列表—详情或媒体浏览。原生遵循平台控件、返回与安全区，H5 验浏览器历史、触控与键盘。 |
| Dashboard / 数据看板 | 按 [看板与图表](data-viz.md) 区分运营处置、探索比较、公开报告。各自优先展示异常、比较口径或结论，图表数据色和界面强调色分别定义。 |
| 其他前端场景 | 登录继承登录后产品的风格，读 [账户流程](account-flows.md)；预约和结账读 [多步任务](task-flows.md)。正文、媒体、地图等按主任务匹配真实同类参考。 |

新方案的构图、配色、组件与动效来自项目的参考、实际内容和外部 Skill 的方法。多场景产品共用项目主规范，页面按任务调整布局与密度。
