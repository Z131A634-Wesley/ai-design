# 数据可视化：先定问题，再选图

| 用户要比较什么 | 优先用什么 |
|---|---|
| 精确读数、多字段比较 | 表格，或图旁配表 |
| 时间变化 | 折线；面积强调总量时从零开始 |
| 排名、离散类别的大小 | 对齐零基线的条/柱；长标签宜横向条 |
| 两个量的关系、分布 | 散点；单变量分布用直方图/箱线图，结合受众解释 |
| 总量组成 | 少量类别可用堆叠条；精确跨组比较用独立条或表；只有部分合计变化时直接标注口径 |

- 标题说明问题或结论；单位、时间范围、口径与取数时间按需要可见。相同指标跨视图保持单位、颜色与格式一致；使用项目的 locale 格式化，不把比例和百分数混用。
- 柱/条和填充用长度/面积表达量值时从零开始；折线可裁剪，明确标注尺度，避免暗示夸大差异。通常不用双 Y 轴；量纲不同先拆为共享时间轴的小图。缺失值不是 0，标明断点；如产品明确做了估算，区别显示并说明。
- 用分类、顺序、发散色标分别编码类别、数量、相对明确基准的偏差。关键含义不能仅靠颜色：加直接标签、形状、线型或可访问的替代内容。不同主题要验证文字、关键线段与背景的对比，不照搬品牌色板。
- 提示信息含值和单位，不靠 hover 才能读到关键内容。按任务提供文字摘要、可访问的等价数据表或其他等效数据路径；移动窄屏减少非核心刻度，不删关键含义。
- 验收样本：正常、缺失、零值、异常量级、长标签；异步图表另验加载、无匹配和失败；手动核对轴、单位、主结论、颜色之外的编码以及触屏/键盘可用性。库和品牌沿用项目现状。

参考：[Carbon 数据可视化](https://www.carbondesignsystem.com/building-blocks/data-visualization/overview)、[Chartability](https://chartability.github.io/POUR-CAF/)、[Observable Plot scales](https://observablehq.com/plot/features/scales)。仅提炼原则，不迁入外部代码、色板或清单。
