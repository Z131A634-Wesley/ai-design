# 基础交互测试样例（不是视觉标杆）

这些早期 HTML 只用来回归流程与状态；不要把它们当高保真参考、设计模板或审美验收证据。需要案例时，按 [多源整合索引](../references/source-map.md) 选实际成品，再按 [视觉方法](../references/visual-craft.md) 拆解。测试样例可直接在浏览器打开，不需要账号和后端。

| 样例与入口 | 设计决定 | 可复验任务 |
|---|---|---|
| [春汛书屋 · 官网](web-landing.html) | Web × 营销 × 页面。用原创 SVG 表达纸张与书脊，分栏 Hero 让价值主张与活动入口靠前，手机转单列。 | 键盘到「查看读书会」；进入读书会区域，标题/入口不被遮挡；宽屏与窄屏无整页横溢出。 |
| [行简 · 账户流程](account.html) | Web × 账户 × 交互演示。单列表单，不套官网框架；保留邮箱，区分字段校验与凭据失败。 | 空提交 → 字段错误；使用内置错误情景 → 错误与恢复；打开找回、提交、回登录；选内置成功情景 → 成功。没有真实凭据、会话或验证码。 |
| [邻里借阅 · 手机端](mobile-list-detail.html) | H5 模拟 App × 列表—详情 × 可点击原型。先显示易扫描的工具列表；返回要恢复搜索；缺货给可行下一步。 | 筛选「钻」→ 详情 → 返回保留查询与焦点；无匹配可一键清空；已借出有替代入口。浏览器视口不等于原生验证。 |

## 手机样例的线框流

| 当前屏 | 主动作 → 下一屏/状态 | 返回与反馈 |
|---|---|---|
| 列表：标题 → 搜索 → 工具及可借状态 | 点工具 → 详情 | 搜索为空显示清空入口 |
| 详情：返回 → 工具名 → 状态 → 下一步 | 可借 → 模拟预约完成；已借出 → 返回筛其他工具 | 返回恢复查询、列表位置和原触发控件（未离开本页时） |
| 预约完成 | 返回列表 | 明示没有发出真实预约 |

其他场景最小样例：后台库存以「低库存 → 筛选 → 批量补货确认」作为一条任务，先核选择范围再画图；多步预约从「选日期 → 核对 → 确认」起步，核对页改日期后直接回核对页，不重走流程。
