# 设计样例

[历史离线小样](design-presets.html) 记录旧版规则，供维护查看。当前设计任务依据 [外部设计 Skill 调用](../references/external-design.md) 与经确认的项目参考。以下交互样例记录场景和操作路径。

三个独立的 HTML 页面，分别演示品牌官网、账户流程和手机端列表—详情。下载仓库后直接用浏览器打开，无需安装依赖、启动后端或登录。以下设计决定来自 [ai-design 的视觉方法](../references/visual-craft.md)，不是所有项目都应照搬的模板。

| 样例 | 设计决定 | 怎么试 |
|---|---|---|
| [春汛书屋 · 品牌官网](web-landing.html) | 把活动编辑成一页河岸刊物：衬线大标题与原创双色版画建立视觉焦点，场次信息改用清楚的列表。窄屏先看文案和主要入口，再看画面。 | 点击「查看读书会」定位到场次。缩窄窗口，对比首屏阅读顺序。 |
| [行简 · 登录与恢复](account.html) | 桌面分为品牌区和表单区，手机只保留轻量品牌头和表单；登录与找回共用同一列宽。示例按钮折在附属区域，不和「登录」争主次。 | 空表单提交后查看字段提示；展开「用示例数据试用」，走失败、找回、返回、成功。请勿输入真实凭据。 |
| [邻里借用 · 手机原型](mobile-list-detail.html) | 工具缩略图、用途和借用状态形成可扫描的目录；详情延续同一个插画，突出可执行的下一步。 | 搜「钻」→ 进详情 → 返回检查查询是否保留；再试无结果、已借出和模拟预约。 |

所有品牌、活动和数据均为虚构。账户和预约只演示界面状态，不发送邮件、不创建会话或订单。手机原型在浏览器中运行，不代表原生平台已经验证。
